# Style Lock

> [!warning] Nowsza instrukcja czeka na potwierdzenie
> 13.11.2026 Game Director przekazał [[Instrukcja promptów — Glossy Ink]] z nowym stałym początkiem i końcem promptu. Nowe prompty piszemy już według niej; ten zapis zostaje do czasu decyzji D-027 w [[Rejestr decyzji]].

Każdy prompt generujący element **2D / UI** dla tej gry **musi zaczynać się** od:

```
Game UI component, hybrid of Shakes & Fidget comic book ink style and vibrant Roblox aesthetic, thick 4px solid black outlines, subtle pop-art halftone dot texture, painterly shading, vibrant saturated colors...
```

## Checklista zgodności grafiki
- [ ] Komiksowe obrysy (grube, czarne 3–4 px)
- [ ] Żywe, nasycone kolory
- [ ] Geometria Roblox voxel / low-poly
- [ ] Ikony UI w ostrym pixel-arcie, w ramce 4 px
- [ ] Tekstura halftone
- [ ] Cel-shading
- [ ] Przerysowane proporcje
- [ ] Zgodność z projektami postaci ([[Rycerz]], [[Kot-Mag]], [[Pety]])

## Narzędzia do generowania
Midjourney / DALL-E 3 / Higgsfield AI dla 2D, Meshy AI i Blockbench dla 3D (zob. [[Narzędzia]]).
